# Scientific visualization catalog

Open `index.html` in a web browser. No build step or server is required.

The catalog contains 103 entries. Select all and Deselect all act on the visible rows. Expand HD(CP)² weather simulation to choose the full four-hour series or the smaller single-time-step subset; the chosen option supplies its download size. Source-reported size labels retain their original units.

Interface text uses Helvetica/Arial with normal capitalization. Scientific acronyms, file names, and source unit labels retain their meaningful capitalization.
